# Cannon Carnival

밝은 놀이공원에서 대포로 구조물을 무너뜨리는 Godot 4 캐주얼 물리 게임입니다.

## 실행

1. Godot 4에서 이 폴더의 `project.godot`을 엽니다.
2. 프로젝트 실행(F6/F5)을 누릅니다.

## 조작과 규칙

- 화면 어디든 클릭하거나 터치하면 해당 방향으로 즉시 발사합니다.
- 포탄이 날아가는 중에도 남은 횟수만큼 연속 발사할 수 있습니다.
- 모든 블록이 실제로 플랫폼을 벗어난 것을 재확인하면 클리어됩니다.
- 발사 횟수가 0이면 마지막 포탄과 블록이 멈춘 뒤 실패를 판정합니다.

## 주요 기능

- 10가지 구조 계열과 레벨별 변형으로 구성된 50개 스테이지
- 레벨에 따라 증가하는 높이, 블록 수, 중량 블록, 회전 속도와 축소되는 플랫폼
- 원통, 목재, 석재, 유리병, 얼음, 폭발 블록
- 유리와 얼음 파편, 폭발 연쇄 충격, 화면 흔들림과 충돌 섬광
- 충격 전에는 고정되고 첫 충돌 뒤 전체 구조물에 중력이 적용되는 블록 물리
- 회전 플랫폼과 함께 움직이는 충격 전 구조물
- 점수, 남은 발사, 남은 블록, 별 평가
- 클리어, 실패, 재시작, 다음 스테이지, 일시정지
- 마우스와 터치 입력, 9:16 세로 화면

## 자동 점검

`tests/level_generation_test.gd`는 50개 레벨이 모두 정상적으로 구조물을 생성하는지 검사합니다.
