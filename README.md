# Cannon Carnival

밝은 놀이공원에서 대포로 타워를 무너뜨리는 Godot 4 물리 게임 프로토타입입니다.

## 실행

1. Godot 4에서 이 폴더의 `project.godot`을 엽니다.
2. 프로젝트 실행(F6/F5)을 누릅니다.

## 조작

- 타워 블록 클릭/터치: 선택한 지점을 자동 조준해 즉시 발사
- 모든 왕관 타깃을 플랫폼 밖으로 떨어뜨리면 클리어
- 발사 횟수가 0이 되면 마지막 포탄이 멈춘 뒤 실패 판정

## 포함 기능

- 3개 순환 스테이지
- 일반/무거운/왕관 타깃 블록
- 정적 및 회전 플랫폼
- 점수, 남은 발사, 타깃 카운트, 별 평가
- 클리어/실패/재시작/다음 스테이지/일시정지
- 마우스 및 터치 입력, 9:16 세로 화면
- 충격 전에는 고정되고 충돌 후에만 연쇄 활성화되는 블록 물리
